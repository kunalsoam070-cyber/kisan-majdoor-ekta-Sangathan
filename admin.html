⚙️ Setup Guide (100% Free)

पहली बार इस्तेमाल से पहले ये 3 step एक बार करें

1️⃣ Firebase Authentication चालू करें

Firebase Console (console.firebase.google.com) → अपना प्रोजेक्ट "kisan-majdoor-ekta-sangathan" खोलें → Build → Authentication → Get Started → Sign-in method में "Email/Password" चालू करें → Users tab में जाकर अपना admin email/password add करें। यह पूरी तरह free है, कोई card नहीं चाहिए।

2️⃣ Firestore Security Rules सेट करें

Firestore Database → Rules में जाकर नीचे दिया rule paste करें, ताकि सिर्फ logged-in admin ही डेटा बदल सके, बाकी सब सिर्फ पढ़ सकें: 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read: if true;
      allow write: if request.auth != null;
    }
  }
}

3️⃣ Free Image Hosting (ImgBB) API Key

api.imgbb.com पर जाकर free account बनाएं और free API key लें (कोई card नहीं चाहिए)। नीचे box में key paste करके "Save" करें — यह आपके browser में ही सुरक्षित रहेगी।

Key ना डालने पर भी आप हर फॉर्म में सीधे "Image URL" पेस्ट करके काम चला सकते हैं।

4️⃣ पुरानी वेबसाइट का डेटा एक बार Import करें (वैकल्पिक)

आपकी पुरानी hardcoded गैलरी तस्वीरें, वीडियो और आंकड़े नीचे बटन दबाकर एक क्लिक में Firestore में जोड़े जा सकते हैं (सिर्फ एक बार चलाएं, बार-बार क्लिक करने से डुप्लीकेट बन जाएंगे)।
